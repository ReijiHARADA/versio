# オンボーディング「使い方」2 ページ

## 目的
- Introduction 論文はユーザーが自分で開く必要があり、見られない可能性が高い。
- 初心者が「慣れた人は初期画面からこう使う」流れ（集める → 読む）を約 20 秒で掴み、ホームが開いたらすぐ真似できるようにする。
- PLaMo をダウンロードする人は、その待ち時間に見られる。

## 非目標・避けること
- 機能ごとの吹き出し・コーチマーク（読まれない）。
- Introduction 論文の変更。

## アプローチ
- **A. 実アプリを台本どおり自動録画（採用）**: ホームと同じ見た目で真似しやすい。UI 変更時は撮り直し（スクリプト 1 本）。
- B. 本物の React 部品でその場デモ: UI に追従するが、作り込みが大きく壊れやすい。
- C. イラスト調 SVG/CSS アニメ: 軽いが実画面と違い、真似しづらい。
- 動画は .app 同梱（署名済みのため表示後に削除できない）。初回 DL して消す案は、オフライン初回起動で見られないことと外部通信が増えることから不採用。HEVC で合計 1〜2 MB を目安にする。

## 設計
- 流れ: イントロ →（PLaMo 未導入なら PLaMo 画面）→ 使い方 1「集める」→ 使い方 2「読む」→ ホーム。ダウンロード／あとで／導入済み、どの場合も表示する。ダウンロードは背景で進む。
- 1「集める」: PDF を数本ウィンドウにドロップ → カードが「準備中 → 読める」→ サイドバーのプロジェクトへドラッグ。
- 2「読む」: 論文を開いて日本語で読む → 段落の原文を開く → マーカー → ⌘K でライブラリ検索。
- 各ページ: 見出し 1 行と短い一文、ループ動画、「次へ」（最後は「はじめる」）、スキップ。
- reduced-motion または動画失敗時: 静止画。
- 録画: Playwright で dev 版を操作し、偽カーソルを重ねる → ffmpeg で HEVC mp4（約 1280px）→ `src/assets/intro/`。`npm run record:howto` で再生成する。サンプル論文は合成 PDF のみ。

## 実装者に任せること
- 文言の細部、ページ遷移のアニメーション、録画の尺と速度、静止画の書き出し方法。

## 確認
- `npm run onboarding:test` で、未導入の流れと導入済みの流れを実機確認する。
