# 初回起動イントロ（ホチキス）設計

## 意図
初回起動の第一印象で「論文を綴じて手元に置く」という Versio の世界観を一発で伝える。最終フレームはアプリアイコンと同じ綴じ跡 + 「Versioを使い始める」CTA。

## 体験（ユーザー確定）
画面＝紙、視点は紙の**裏側**。
1. 真っ白な画面（紙）
2. 巨大なホチキスの**下あご（受け皿）**が裏側から急に迫り画面を覆う
3. パチンと閉じる（紙と画面がわずかに揺れる）
4. 受け皿が引くと中央にアイコンと同じ折れた脚の綴じ跡が残る
5. 下に「Versioを使い始める」CTA がフェードイン

## 作り方（ユーザー確定：Blender でリアルに）
- `design/intro/stapler_intro.py`：Blender ヘッドレスで受け皿・紙・綴じ跡を作りアニメーションをレンダー。綴じ跡の形状・鋼材マテリアルは `design/icon/staple_icon.py` と同じ定義を流用し、アイコンと見た目を一致させる。
- ffmpeg で H.264 MP4（WKWebView で確実に再生できる）に書き出し、`src/assets/intro/` に同梱。約 2.5 秒、1MB 前後を目安。
- 最終フレームを PNG でも書き出し、reduce motion 時・動画失敗時はそれを即表示。

検討した他案：CSS/SVG 描画（軽いがアイコンの 3D 質感と合わない）、Lottie（依存追加、同上）。ユーザーの指定どおり Blender 動画。

## アプリ側（Claude の判断）
- `IntroOverlay` を App ルートに全面オーバーレイで置く（ルートは増やさない）。
- 表示判定：`localStorage` の `versio.introSeen`。CTA 押下 or スキップで記録。途中終了は未記録（次回また出る）。
- スキップ：右上の「スキップ」ボタンと Esc。
- 「パチン」音：Web Audio で短いノイズ + 金属共鳴を合成（音素材のライセンス問題を避ける）。閉じる瞬間に動画の時刻で発火。
- 紙は明暗どちらのモードでも白（コンセプト優先）。CTA 押下でオーバーレイがフェードアウトし Library が見える。
- `prefers-reduced-motion` 時は最終フレーム静止画 + CTA のみ。

## 非目標
複数ページのウェルカム、機能説明、設定画面からの再生（必要なら後で）。

## 確認
`npm run verify:browser` 相当でブラウザ確認 + スクリーンショット、最後に `.app` で再生・音・記録を確認。
